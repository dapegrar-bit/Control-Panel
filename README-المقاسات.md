# تحديث الحفاظ على مقاسات الشهادات والخطابات

- استبدلي `index.html` الموجود في GitHub Pages بهذا الملف.
- اتركي مجلد `templates` الأصلي كما هو.
- لا حاجة لتغيير SQL أو server.js.
- تقرأ المعاينة العرض والارتفاع الطبيعيين لكل صورة ولا تكبّرها فوق عدد بكسلاتها.
- عند الطباعة إلى PDF يتم تحديد صفحة بنفس نسبة أبعاد الصورة الأصلية، دون تمديد أو اقتصاص، ودون تكبير عن مقاسها المحسوب عند 96 DPI؛ وقد تُصغّر لتناسب الحد الأقصى A4.
- اختاري في نافذة طباعة المتصفح: حفظ PDF، الهوامش None/بلا، المقياس 100%، وإلغاء Headers and footers. بعض المتصفحات لا تحترم حجم الصفحة المخصص بالكامل.
- تنبيه: الصور لا تضمن وجود قيمة DPI أصلية؛ الحفاظ الدقيق على المقاس الفيزيائي بالسنتيمتر يتطلب بيانات DPI أو أبعادًا فعلية لكل قالب.
- PDF التجريبي المرسل A4 أفقي؛ الكود السابق فرض A4 على كل صورة مما أدى إلى تشوه نسب الأبعاد.
