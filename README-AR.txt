طريقة التركيب:
1. افتحي Supabase > SQL Editor وشغّلي محتوى migration_import.sql مرة واحدة.
2. استبدلي ملفات index.html وserver.js وpackage.json في GitHub بنفس الأسماء.
3. اتركي config.js وإعدادات Render كما هي.
4. انتظري اكتمال نشر GitHub Pages وRender.
5. سجّلي الدخول بصلاحية admin، ثم اختاري ملف XLSX، اضغطي معاينة ثم تأكيد الرفع.
6. لا ترفعي ملفات المتدربين إلى مستودع GitHub العام.
7. منع التكرار هنا يعتمد على بصمة الملف نفسه؛ الملفات المختلفة التي تتضمن صفوفًا مكررة قد تكرر البيانات.
8. ملاحظة: عملية رفع 50 ألف سجل قد تستغرق وقتًا طويلًا، وقد تتأثر بمهلة الاتصال على Render المجاني. اختبري ملفًا صغيرًا أولًا.
9. لا تستبدلي schema.sql على قاعدة البيانات؛ استخدمي migration_import.sql فقط.
