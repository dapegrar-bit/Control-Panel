# الشهادات والخطابات — الإصدار المرتبط بالأرشيف الأصلي

## ماذا يحتوي التحديث؟
- 20 قالبًا صالحًا للاختيار، موزعة على 7 دفعات: الخامسة والسادسة والسابعة والثامنة والعاشرة والحادية عشرة والثانية عشرة.
- صورة إضافية بعنوان «نموذج إشعار القبول» في `templates/batch-5/admission-notice-reference.jpg`، **لم تُدرج كشهادة حضور** لأنها إشعار قبول وليست شهادة حضور.
- مجلد `templates` يتضمن صور القوالب الأصلية التي رفعتها، دون تعديل محتواها.
- `document-templates.js` يربط كل قالب بدفعته ونوعه وصورته وإحداثيات الاسم المبدئية.
- `index.html` فيه محرر موضع الاسم بالسحب أو إدخال الإحداثيات، والتحكم بالحجم واللون والعرض، وزر حفظ موضع القالب.
- `server.js` يوفر قراءة وحفظ المواضع في قاعدة البيانات مع قصر الحفظ على المدير.
- `documents-schema.sql` لإنشاء جدول سجل الإصدار وجدول مواضع الأسماء.

## خطوات التركيب
1. **خذي نسخة احتياطية من الموقع وقاعدة البيانات**.
2. افتحي Supabase SQL Editor وشغلي `documents-schema.sql` مرة واحدة. لا تحذفي الجداول القديمة.
3. ارفعي الملفات `index.html` و`server.js` و`document-templates.js` ومجلد `templates/` بالكامل إلى جذر مستودع GitHub بجوار `config.js` و`package.json`.
4. لا تحذفي ملفات الموقع الحالية الأخرى. سيُنشر `index.html` عبر GitHub Pages، و`server.js` عبر Render بعد نشر التغييرات.
5. سجلي الدخول بحساب المدير، وافتحي صفحة الشهادات والخطابات، وابحثي عن متدرب، واختاري القالب، واسحبي الاسم إلى موضعه، ثم اضغطي «حفظ الموضع للقالب».
6. جربي طباعة مستند تجريبي ومطابقة موضع الاسم على الورق قبل الاستخدام الحقيقي.

## ملاحظات مهمة
- تتعرف المطابقة على `الدفعة الخامسة` و`الدفعة 5` و`5`، وكذلك الأرقام العربية. قد تحتاج أسماء الدفعات المختلفة جذريًا إلى تخصيص.
- إحداثيات الاسم المبدئية **تقديرية**، لأن التصاميم تختلف. راجعي كل قالب واحفظي موضعه قبل الإصدار.
- لون اسم الشهادات `#1F4E46`؛ أسماء الخطابات ذات الخلفية الداكنة بيضاء.
- خط DIN Next LT Arabic يتطلب توفير ملف `assets/fonts/din-next-lt-arabic.woff2` المرخص؛ لا نرفق الخط دون ترخيص.
- لا تُدرج دفعات أو أنواع شهادات لم تكن موجودة في الأرشيف. **الشهادات الناقصة لا يتم توليدها تلقائيًا**.
- يسجل النظام «تجهيز للطباعة» ولا يؤكد أن المستخدم طبع فعليًا.
- المواضع المحفوظة عامة للقالب، وليست تخصيصًا منفصلًا لكل متدرب.
- صور الشهادات ذات بيانات متدربين محتملة؛ لا ترفعي مستندات تحتوي معلومات شخصية حقيقية إلى مستودع GitHub عام قبل إزالة تلك المعلومات.
- لم يتم اختبار تشغيل Render وSupabase من داخل بيئتك الفعلية؛ فحص الصياغة لا يساوي اختبارًا إنتاجيًا.
