# تحديث إظهار الخطابات لجميع المتدربين

1. شغّلي `add-universal-letter.sql` في Supabase SQL Editor **بعد** إنشاء جدول `trainee_document_templates`.
2. ارفعي `index.html` إلى مسار نشر GitHub Pages، وارْفعي `templates/general/letter.svg` إلى المسار نفسه مع المحافظة على المجلدات.
3. استبدلي `server.js` على خدمة Render ثم أعيدي نشر الخادم.
4. افتحي صفحة الشهادات والخطابات، وابحثي عن متدرب واختاريه: يظهر الخطاب أولًا ومحددًا تلقائيًا، حتى إذا لم يكن لدفعته قالب خطاب خاص.
5. إذا توفر خطاب أصلي خاص بدفعته في قاعدة البيانات فسيظهر ذلك الخطاب بدل العام؛ وتبقى شهادات الدفعة متاحة للاختيار.

## ملاحظات مهمة
- الخطاب العام هو **خطاب إفادة محايد**، وليس شهادة اجتياز أو إثبات إكمال تدريب.
- لا تُنشأ خطابات أصلية مفقودة أو شهادات تلقائيًا، ولا تتغير سجلات المتدربين.
- حفظ موضع الاسم يتم بواسطة المدير كما في النسخة السابقة.
- السجل التدقيقي يُنشأ عند الضغط على إصدار، وليس عند مجرد البحث.
- قد يحتاج Render إلى إعادة نشر لكي يقرأ تحديث server.js. رابط API_BASE في config.js يجب أن يشير إلى Render الأصلي إذا كان data.myacademy.sa هو نطاق GitHub Pages.
- يلزم اختبار النشر والاتصال بقاعدة بيانات Supabase الفعلية؛ لم يُنفذ SQL عليها هنا.
