# تحديث القوالب من آخر أرشيف حتى الدفعة الثالثة عشرة

الملف يحوي 24 قالبًا أصليًا: 20 شهادة و4 خطابات. الخطابات متوفرة فقط للدفعات الخامسة والسادسة والسابعة والثالثة عشرة. لا يوجد خطاب في أرشيف الدفعة الثانية عشرة، ولذلك لن يظهر لها خيار الخطاب. استُبعدت صورة «نموذج إشعار القبول» من شهادات الدفعة الخامسة لأنها ليست شهادة حضور.

## التثبيت
1. بعد التأكد من تشغيل `documents-schema.sql` و`document-templates-registry.sql` السابقين، شغّلي `update-templates-13.sql` في Supabase SQL Editor.
2. ارفعي `index.html` ومجلد `templates/` **بكامل محتوياته** إلى مجلد النشر في GitHub Pages؛ يجب أن تكون الصور متاحة على نفس مسارات `image_path` الموجودة في SQL.
3. لا حاجة لتعديل `server.js` إذا كانت واجهة `/api/documents/templates` تعمل بالفعل.
4. انتظري اكتمال نشر GitHub Pages ثم Ctrl+F5، وابحثي عن متدرب من الدفعة الثالثة عشرة: سيظهر الخطاب تلقائيًا أولًا. جرّبي الدفعة الثانية عشرة: لن يظهر لها خطاب.
5. لم يُجر اختبار مباشر مع قاعدة بيانات Supabase أو موقعك المنشور. قد تتطلب مواضع الأسماء ضبطًا بصريًا من محرر الموقع.

**مهم:** لا تضيفي خطابًا عامًا، ولا تعيدي تشغيل `add-universal-letter.sql`. التحديث يحافظ على القوالب الإضافية الموجودة مسبقًا، لكنه لا يعرض قالبًا عامًا مفعّلًا بالمعرف `all-batches-letter`.
