# إضافة الشهادات والخطابات — دليل التركيب

## الملفات
- `index.html`: صفحة «الشهادات والخطابات» والبحث والمعاينة والطباعة.
- `server.js`: واجهات البحث والتوثيق وسجل الإصدارات.
- `document-templates.js`: تعريف قوالب كل دفعة ونوع المستند وموضع الاسم.
- `documents-schema.sql`: جدول سجل الإصدار، يُشغّل مرة واحدة في Supabase SQL Editor.
- `templates/batch-1/*.svg`: قوالب **تجريبية فقط** قابلة للاستبدال بصور الشهادات والخطابات الرسمية.

## التثبيت
1. خذي نسخة احتياطية من قاعدة البيانات وملفات الموقع.
2. ارفعي الملفات إلى جذر مستودع GitHub بنفس المسارات، بما فيها مجلد `templates`.
3. شغّلي محتوى `documents-schema.sql` في SQL Editor الخاص بمشروع Supabase نفسه، بعد مراجعة صلاحيات التنفيذ.
4. في `document-templates.js` استبدلي `الدفعة الأولى` بالقيمة الدقيقة في عمود `الدفعة`، وكرري أربعة تعريفات لكل دفعة: حضور، اجتياز، اجتياز بتميز، خطاب.
5. ارفعي صورة كل مستند، ثم اضبطي `name.x` و`name.y` و`name.size` و`name.width` في تعريف القالب. اللون الافتراضي للشهادات `#1F4E46`؛ الخطابات أبيض `#FFFFFF` للخلفية الداكنة أو أسود `#000000` للخلفية الفاتحة.
6. **الخط DIN Next LT Arabic** خط مرخّص: إن كنت تملكين ترخيص استضافة ويب، ضعي ملف `din-next-lt-arabic.woff2` في `assets/fonts/`. لا يُضمّن هذا الملف في الحزمة. بدونه يستخدم المتصفح خطًا بديلًا.
7. انتظري نشر GitHub Pages وRender، ثم اختبري على متدرب تجريبي وقالب تجريبي.

## السلوك والصلاحيات
- البحث في جميع الحقول النصية عن أي جزء من النص، مع حد 40 نتيجة لكل بحث.
- يُظهر النظام فقط قوالب الدفعة المطابقة تمامًا لعمود `الدفعة`، ويعرض اسم المتدرب فوق صورة القالب.
- يُسجل كل تجهيز للطباعة: المستند والدفعة والمتدرب والحساب (البريد إن توفر) ودور الحساب والتاريخ.
- **الإصدار الافتراضي مسموح للمدير admin والمصدّر exporter فقط**. لتغيير ذلك ضعي متغير Render `DOCUMENT_ISSUER_ROLES` بقيم مثل `admin,exporter,viewer` بعد اعتماد السياسة. جميع الحسابات المصادق عليها يمكنها البحث ورؤية سجل الإصدار في هذه النسخة.
- سجل «إصدار» يعني **تجهيز نسخة للطباعة**؛ لا يستطيع الخادم التأكد من ضغط زر «طباعة» أو حفظ ملف PDF في المتصفح.
- إذا حُذف سجل متدرب لديه إصدارات، سيمنع قيد قاعدة البيانات حذفه حفاظًا على السجل التدقيقي. يلزم قرار إداري بشأن سياسة الأرشفة أو الحذف.

## تنبيهات
- النماذج المرفقة أمثلة وليست شهادات رسمية. يجب رفع صور التصاميم الأصلية.
- القوالب محددة في ملف JS مشترك بين الواجهة والخادم؛ لا تستخدمي معرفات مكررة.
- يُستحسن تطبيق حماية إضافية على سجل الإصدارات وفق سياسة خصوصية المنشأة، وتقييد مشاهدته بالأدوار المصرح لها عند الحاجة.
